# Portfolio (React + Vite + Tailwind v4 + Motion)

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
npm run preview
```

## Edit content
- `src/data/profile.js`: name, roles, intro, email, social links (replace every PLACEHOLDER).
- Put your photo at `public/images/profile.jpg` (initials show until then).
- More data files (projects, media, research, leadership, skills) arrive in the next phases.
